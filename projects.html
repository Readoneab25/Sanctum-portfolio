/projects/clinic-manager Shipped

Clinic Management System

Desktop app · Windows PC

Built to move a clinic off paper files entirely. Handles the day-to-day of running the front desk: keeping patient records accurate, generating bills, and printing physical patient ID cards — with backups so records are never at risk of being lost.

  • Create, edit, and manage patient records
  • Billing workflow built in
  • Print patient ID cards directly from the app
  • One-click backup to PDF and to JSON
  • Password-protected login, with password change support
Desktop software CRUD / records PDF export Data backup Auth
Currently in use managing a real clinic's patient records
